# Picture to Model — 產品規格

版本：0.2（規劃草案）｜日期：2026-09-20

## 1. 產品目標與預設

讓使用者上傳一張物件圖片，透過 AI 取得帶材質的 3D 模型，再透過一般 3D 操作介面調整，最後下載 GLB 或發布成可嵌入網站的展示內容。

第一版定位為網站商品、擺飾、道具的視覺展示工具。以下是可調整的規劃預設，不代表已由使用者確認：單一物件、單張圖片、桌面編輯、單一擁有者；手機先支援觀看。先在本機完成流程，對外部署前加入登入與存取隔離。

成功標準：使用者不需操作 Blender，即可完成「上傳 → 生成 → 調整 → 儲存 → 匯出 → 嵌入」，且下載檔與發布版本保留相同的模型調整。

## 2. 邊界

- AI 僅用於明確啟動的模型生成；重新生成建立另一個版本，可能產生費用，不覆蓋已有編輯。
- 編輯、匯出、減面與貼圖縮小不得呼叫生成式 AI 或供應商的 AI remesh／retexture 服務。
- 單張圖片中的遮擋與背面由模型推測，不能保證與實物一致。沒有尺度參照時，尺寸由使用者指定。
- MVP 不包含雕刻、逐點／逐面編輯、語意分件、骨架動畫、CAD 精度、保證可列印的封閉網格、多視角生成或自架 GPU 模型。
- 網站展示是優先用途；STL、OBJ、USDZ 及 3D 列印修復留到有明確需求時處理。

## 3. 使用流程與頁面

1. **專案列表**：建立專案、查看縮圖與狀態、開啟或刪除專案。
2. **上傳／生成**：上傳圖片、查看預覽、命名模型；說明圖片將傳給第三方生成服務，顯示預估費用或「無法估算」後啟動生成。
3. **生成狀態**：區分排隊、生成、下載、驗證、完成與失敗。沒有真實百分比時只顯示階段。重新整理後可繼續追蹤。
4. **模型編輯**：左側物件樹，中間 3D 視窗，右側屬性面板；上方儲存、復原、重做、匯出、發布。提供載入錯誤與效能提示。
5. **匯出／網站整合**：選擇已儲存版本，可單獨下載 GLB，或選擇 iframe、GLB＋model-viewer、GLB＋Three.js 三種整合方式。只有 iframe 需要發布；自託管下載不改變專案的私有狀態。

## 4. 功能規格與驗收

### F01 圖片輸入（MVP）

- 接受 PNG、JPEG，產品初始上限 10 MB、最長邊 4096 px、總像素 16 MP；實作時依供應商限制再轉換。這些是產品限制，不是供應商能力聲明。
- 檢查檔頭、實際解碼尺寸與內容，拒絕損毀檔、偽裝副檔名及超限圖片；移除 EXIF 後再傳送供應商。
- 建議完整物件、清楚輪廓與簡單背景；MVP 不提供 AI 去背，日後可增加手動裁切。
- 驗收：有效圖片能建立專案；不合格輸入在送出付費請求前被阻擋，原因可理解。

### F02 非同步 AI 生成（MVP）

- 第一版只接一個供應商，以 adapter 保留替換能力。每次生成記錄來源圖片、供應商、模型版本、參數、任務 ID、時間與可取得的費用資料。
- 預設每位擁有者一次只跑一個生成任務；後端具每日預算／點數額度設定。費率未知或變動時，不顯示虛構精確價格。
- 重複點擊不重複提交。查詢與下載可有限重試；提交結果不明時先對帳，不盲目建立新的付費任務。
- 供應商完成後下載到自己的儲存空間並驗證 GLB；短效供應商 URL 不作為永久模型網址。
- 驗收：成功、失敗、逾時、斷線與服務重啟都有明確結果；重試下載不重新生成。

### F03 3D 預覽與非 AI 調整（MVP）

| 操作 | 行為 | 儲存／匯出 |
| --- | --- | --- |
| 觀看 | 軌道旋轉、縮放、平移、重設視角 | 初始相機儲存於展示設定 |
| 模型變換 | 整體平移、旋轉、等比縮放；指定某一軸目標尺寸 | 寫入模型根節點 transform |
| 軸向校正 | 90° 快捷旋轉、設為正面、置中、貼地 | 模型變換保存；正面視角另存 |
| 部件操作 | 選取既有 mesh、顯示／隱藏、重設 | 隱藏部件不輸出；禁止隱藏全部可渲染部件 |
| 材質 | 依既有材質槽調整 base color、metalness、roughness | GLB PBR 材質 |
| 貼圖開關 | 原有 base color 貼圖的啟用／停用 | 反映於材質引用 |
| 展示 | 背景、環境光強度、陰影、自動旋轉、初始視角 | 僅展示設定，不宣稱已烘焙進 GLB |
| 編輯歷史 | 復原／重做、回到生成原始狀態 | 儲存產生不可變 revision |

尺度採公尺，介面允許 cm／m 輸入。尺寸是使用者設定值，不能當成 AI 測量結果。MVP 暫不支援非等比縮放、鏡射與個別部件移動，以降低破面及組裝問題。

AI 模型可能只有單一 mesh 或共用材質，介面不承諾「椅腳」「把手」等語意部件。共用材質的變更影響所有引用部件，選取時提示；base color 會與貼圖相乘，純色效果需停用貼圖，並非自動重繪紋理。

驗收：在編輯期間監測網路請求，確認無 AI 呼叫；儲存後重開保留所有數值；復原／重做還原模型與材質；空模型不能匯出。

### F04 非 AI 優化（第二階段）

- 對已儲存 revision 提供確定性的減面與貼圖縮小，先預覽再另存版本，不覆蓋來源。
- 顯示前後三角面數、檔案大小與貼圖尺寸；減面可能影響細節、UV 和輪廓，失敗時保留可用原檔。
- 先用 glTF Transform 等一般幾何工具驗證；若需更多網格修復，再導入 headless Blender。是否需要 Blender 不作為 MVP 啟動前提。
- 驗收：相同輸入、參數與工具版本可重現；能取消採用結果；優化後仍有材質且能重新載入。

### F05 儲存與 GLB 匯出（MVP）

- 保留原始生成 GLB，編輯狀態以帶 schema 版本的 JSON 儲存，每次儲存建立 revision。
- GLB 匯出包含幾何、可見部件、材質、貼圖和模型變換；不包含格線、gizmo、選取框或純展示背景。
- MVP 輸出自包含 GLB，無外部貼圖依賴；暫不啟用需要額外解碼器的壓縮擴充。
- 未儲存編輯時，匯出動作先建立 revision；匯出任務綁定 revision，過程中的新編輯不能改變其結果。
- 驗收：將檔案重新載入獨立檢視器，比較尺寸、方向、可見部件與材質數值；不同光照下不要求像素相同。

### F06 三種網站整合選項（MVP）

三種選項共用 F05 產生的已驗證 GLB，不重新生成模型，也不呼叫 AI。匯出面板顯示版本、輸出內容及是否需要公開發布；單獨下載 GLB 的入口始終保留。這三種是交付／整合方式，模型格式均為 GLB。

| 選項 | 適合對象 | 交付內容 | 託管與發布 |
| --- | --- | --- | --- |
| A. iframe 嵌入 | 希望直接貼上網站或 CMS 的使用者 | 公開展示網址、可複製的 iframe 程式碼 | 本系統託管，需明確發布 |
| B. GLB＋model-viewer | 可修改 HTML、希望自行託管網站的使用者 | ZIP：model.glb、viewer.config.json、poster、HTML／JS 範例與 README | 使用者自行託管，無需發布 |
| C. GLB＋Three.js | 需要整合網站互動的開發者 | ZIP：model.glb、viewer.config.json、poster、可執行的 Three.js 範例專案與 README | 使用者自行託管，無需發布 |

#### A. iframe 嵌入與發布

- 自有展示頁採 `<model-viewer>`，提供 orbit 操作、poster、loading／error／WebGL 不可用時的替代顯示。
- 提供 iframe 碼，可設定寬高、alt 文字、自動旋轉；模型與視角取自固定 revision。
- 預設專案私有，使用者明確發布才產生無需登入的展示網址。之後的編輯不自動影響已發布內容，更新需再次發布。
- 取消發布使展示页與受控模型端點失效；不能收回訪客已下載的副本。MVP 公開模型回應使用 `no-store`，避免長期 CDN 快取妨礙撤回。
- 驗收：另一個 origin 的測試頁能嵌入，無登入即可觀看已發布內容；未發布、已撤回內容回傳 404，不能藉由私有資產 URL 讀取。

#### B. GLB＋model-viewer 自託管套件

- 提供可透過 HTTP 靜態伺服器預覽及部署的範例，直接在頁面載入模型，不使用 iframe。
- 包含模型載入、旋轉／縮放、響應式尺寸、poster、替代文字、載入與失敗提示，以及初始視角、背景和自動旋轉設定。
- README 說明模型路徑替換、啟動方式、HTTPS、GLB MIME type、跨來源資產 CORS 及依賴版本。不得假設雙擊 HTML 的 `file://` 模式可正常使用。
- 驗收：ZIP 解壓後依 README 啟動即可顯示指定版本；無需本系統帳號、API key 或私有資產端點，也不會自動發布專案。

#### C. GLB＋Three.js 開發者套件

- 提供最小可執行專案，包含場景、相機、renderer、GLB loader、orbit 操作、基礎光照、視窗 resize、載入／失敗提示及資源釋放。
- 附模型載入完成與物件點選的事件接點，讓開發者接入自己的介面；不承諾語意部件辨識，點選以匯出後實際 mesh 為準。
- 提供依賴版本、lockfile、開發與建置命令及部署說明；套件不包含完整模型編輯器。自訂動畫、部件互動或特殊效果由整合方開發。
- 驗收：乾淨目錄中依 README 安裝、啟動及建置成功；模型可顯示、操作及取得點選事件，無需連回本系統。

#### 共用設定與一致性

- 兩種下載套件皆綁定固定 revision，包含帶 schema version 的展示設定；模型變換已在 GLB 中，不再重複套用。
- 展示設定包含相機、背景、自動旋轉及光照／陰影偏好。各 viewer 需有明確欄位映射；無法等效支援的設定在下載前與 README 列出，不靜默忽略，不保證不同 renderer 像素一致。
- 自託管套件內的模型、poster 與必要環境素材採相對路徑，只打包有再散布權的資產。第三方 runtime 依賴固定版本，外部下載需求需明列；MVP 不承諾完全離線安裝。
- 套件不含機密、私有網址、短效簽名 URL 或追蹤憑證。模型名稱與替代文字須安全編碼，不能插入可執行 HTML／JS。
- 自託管副本由使用者管理，不受本系統撤回發布或刪除專案控制。
- 驗收：A／B／C 使用相同 revision 的 GLB，模型尺寸、方向、材質與可見部件一致；B／C 在本系統停止後仍能依已宣告的第三方依賴正常展示。

## 5. 非功能需求

- **效能預算（待實測）**：網站版目標 ≤ 15 MB、≤ 100k triangles、貼圖最長邊 ≤ 2048 px；MVP 超標提示，不自動以 AI 修正。輸入 GLB 硬上限初設 100 MB，另限制解壓後材質／幾何記憶體。
- **可用性**：編輯先驗證桌面 Chrome／Safari／Firefox；展示增加 iOS Safari／Android Chrome。以記錄型號的參考手機，10 Mbps 網路下目標 15 秒內可操作、旋轉時至少 30 FPS；Phase 0 確認測試裝置與預算。
- **安全**：API key 僅在後端；資產讀寫檢查擁有者；供應商下載驗證 HTTPS、主機白名單與重新導向；拒絕私有網路 URL，GLB 不得引用外部 URI。
- **部署**：未加入登入前只綁定 localhost；公開環境需 HTTPS、登入、owner 隔離、請求限流與儲存配額。iframe 的 frame-ancestors 政策只對展示路由放行，編輯介面不可被嵌入。
- **可追蹤性**：日誌帶內部 task ID；遮蔽金鑰、簽名 URL 與敏感圖片資料；提供各階段耗時與失敗原因。
- **刪除**：刪專案先撤回所有 publication，再排程清除資產；進行中的生成停止後续處理，供應商是否可取消及保留多久依其政策另行確認。

## 6. 端到端完成條件

至少一個真實 AI 生成模型與一組固定測試 GLB 跑完流程：上傳、追蹤、編輯、復原／重做、重新開啟、下載再載入、iframe 跨站嵌入與撤回，以及 model-viewer／Three.js 套件的獨立啟動與部署。網路中斷及服務重啟不遺失已儲存版本，也不自動多扣一次生成費用。

## 7. 待驗證決策

1. 主要圖片類別：先以單一商品／道具測試；若是人物、房間或精密零件，需要重估範圍。
2. AI 供應商與每次生成可接受成本：Phase 0 使用同一組樣本比較後決定。
3. 是否需要真正改變局部形狀：本版只承諾上述操作；雕刻與局部幾何編輯需獨立規格。
4. 公開服務是否有多使用者、收費與長期託管需求：不阻礙本機 MVP，但會影響部署階段。
